# Linux DO 楼中楼阅读

把 LINUX DO 的回复按讨论关系串起来看，也可以切回按楼层顺序阅读的引用模式。

**当前版本：v6.0.13** · [论坛分享与反馈](https://linux.do/t/topic/3021097) · [更新记录](CHANGELOG.md)

## 安装 / 更新

1. 浏览器安装篡改猴（Tampermonkey）等用户脚本管理器，并允许访问 `linux.do`。
2. [打开完整脚本](https://raw.githubusercontent.com/mengxiaoww/linuxdo-threaded-reader/main/linuxdo-comments.user.js)。管理器若出现安装页，按提示安装；否则复制全部代码，在管理器中新建脚本并完整替换。
3. 保存后刷新已经打开的话题。更新旧版时替换原脚本，避免同时启用两份。

仓库中的脚本保留原始排版，没有压缩。下载文件位于 [linuxdo-comments.user.js](linuxdo-comments.user.js)。

## 功能

- **楼中楼**：同一串讨论放在一起，按真实回复关系递进，同级对齐，浅灰弯折线连接头像；窄屏限制缩进。
- **引用**：恢复论坛原来的楼层顺序及进度。保留原有引用，只为缺少同一父评论引用的回复补充上下文。
- **原生操作**：点赞、回复、Boost 和解决方案沿用论坛组件。
- **自动分页**：长帖每批最多 20 条，接近底部继续加载；跳到末尾后，上滑会补取前页并保留当前评论位置。缺少父评论时单独取上下文，不扫描中间几百层。
- **进度**：楼中楼按顶层回复等权计算，首帖和楼内回复不重复计数。`顶层回复 19 / 31` 表示已加载 19 条、总共 31 条。直接跳末尾显示定位进度，不代表中间内容全部读过。
- **日期定位**：上方日期回开头，下方日期到整个评论区末端；目标已加载时直接滚动，未加载时允许导航获取。
- **新回复**：后台检查，标记放在用户名附近；阅读后消失，不占时间位置。阅读标记保存在当前浏览器。

只整理话题评论区。篡改猴菜单中可以临时开启或关闭。

## 验证

需要 Node.js 20.19+（jsdom 30 的要求）。

```sh
npm ci
npm test
```

测试覆盖顶层进度、嵌套与深链接、首帖、原生组件调用、漏载补齐、自动分页、末尾跳转及快速反向滚动锚点。浏览器验收另外检查了两万多层长帖、引用切换、历史返回、320 / 390 像素窄屏及桌面溢出；自动化测试不代替所有论坛主题和扩展组合的兼容性验证。

论坛改版可能影响原生组件接口；遇到问题请附话题链接、复现步骤和截图。
